Important:
The contact form is intentionally front-end only. Do not put a Mailjet API key in browser JavaScript.
For actual email delivery, connect the form to EmailJS, FormSubmit, a small Node endpoint, or another server-side email service.
For text, the SMS button opens the visitor's texting app. If you later want automated SMS from the website, use a server-side provider such as Twilio.

Replacing photos:
Put your actual JPG/PNG files in /images and update the <img src="..."> paths in the HTML.
